# 🚀 XGBoost Classification on Customer Churn Prediction

This project demonstrates **Extreme Gradient Boosting (XGBoost)** for predicting customer churn using the **Churn_Modelling.csv** dataset.

The project includes complete machine learning workflow from preprocessing to model evaluation and visualization.

---

## 📂 Dataset

Dataset Used:

- Churn_Modelling.csv

Target Variable:

- Exited
  - 0 → Customer Stays
  - 1 → Customer Leaves

---

## 📌 Features

- Data Preprocessing
- Label Encoding
- One Hot Encoding
- Train-Test Split
- XGBoost Classifier
- Prediction
- Confusion Matrix
- Accuracy Score
- Bias vs Variance
- 10-Fold Cross Validation
