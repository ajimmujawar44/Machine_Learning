# 🌳 Decision Tree Classification

This project demonstrates the implementation of the **Decision Tree Classification Algorithm** using **Python** and **Scikit-Learn**.

---

# 📌 Project Overview

Decision Tree is a supervised Machine Learning algorithm used for solving classification problems by recursively splitting the dataset based on feature values.

This project includes:

- Data Preprocessing
- Train-Test Split
- Feature Scaling
- Decision Tree Classifier
- Gini Index
- Entropy (Information Gain)
- Confusion Matrix
- Accuracy Score
- Bias & Variance Analysis
- Decision Boundary Visualization
- Hyperparameter Tuning


Run the project

