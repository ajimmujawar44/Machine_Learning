# 🌟 LightGBM Classification on Customer Churn Prediction

This project demonstrates **Light Gradient Boosting Machine (LightGBM)** for customer churn prediction.

The complete machine learning pipeline is implemented including preprocessing, training, prediction, evaluation and visualization.

---

## Dataset

Churn_Modelling.csv

Target:

Exited

---

## Features

- Data Cleaning
- Label Encoding
- One Hot Encoding
- Train Test Split
- LightGBM Classifier
- Accuracy Score
- Confusion Matrix
- Bias vs Variance
- Stratified K Fold Cross Validation
- Graphical Analysis
